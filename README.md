# chin-up

常駐在系統匣的坐姿提醒小工具。

- **久坐提醒**：連續使用電腦 15 分鐘就提醒你起來動一動、做收下巴運動。離開電腦超過 5 分鐘會自動重新計時。
- **姿勢偵測**（有 webcam 才會開）：頭往前伸（烏龜頸）或身體往下滑（駝背）持續 10 秒就跳通知。

沒有鏡頭的電腦會自動改成只做久坐提醒。

## 安裝

需要 Python 3.14。

```
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

## 使用

雙擊 `start.bat`，右下角系統匣會出現一個箭頭圖示（可能藏在 `^` 裡）。

第一次啟動會請你**坐正、看著螢幕**，3 秒後自動校正，之後就以這個坐姿當標準。換座位、調整螢幕或鏡頭角度後，請在圖示上按右鍵 →「重新校正坐姿」。

| 圖示顏色 | 意思 |
|---|---|
| 綠 | 姿勢良好 |
| 橘 | 姿勢不良 |
| 灰 | 沒看到人／已暫停 |
| 藍 | 沒有鏡頭，只做久坐提醒 |

暫停時會關掉鏡頭。

### 開機自動啟動

按 `Win + R`，輸入 `shell:startup`，把 `start.bat` 的捷徑放進打開的資料夾。

## 設定

第一次校正後會產生 `config.json`，可以直接修改（改完要重新啟動）：

| 設定 | 預設 | 說明 |
|---|---|---|
| `sit_minutes` | 15 | 連續坐多久提醒一次 |
| `idle_reset_minutes` | 5 | 離開電腦多久，久坐計時歸零 |
| `use_camera` | true | 設成 false 就只做久坐提醒 |
| `bad_posture_seconds` | 10 | 姿勢不良持續多久才提醒 |
| `posture_cooldown_seconds` | 60 | 兩次姿勢提醒的最短間隔 |
| `size_tolerance` | 0.15 | 臉比校正時大 15% 算頭往前。太常誤報就調大 |
| `y_tolerance` | 0.06 | 臉比校正時低多少算駝背。太常誤報就調大 |

出錯時看 `chin-up.log`。

## 原理

用 OpenCV 的 YuNet 人臉偵測（`models/` 裡的模型，來自 [opencv_zoo](https://github.com/opencv/opencv_zoo)）找出臉在畫面中的位置：

- 頭往前伸 → 臉離鏡頭變近 → 臉框變大
- 駝背、低頭 → 臉在畫面中往下掉

影像只在本機處理，不會存檔也不會上傳。
